# Pricing Documentation: Enterprise AI Platform

## Tier Structure

### 1. Growth Tier
- **Annual License**: ₹12,00,000 / year (₹12L)
- Up to 5 connected agents
- Standard multi-tenant cloud deployment
- Standard 8x5 support SLA (4-hour response time)

### 2. Enterprise Core Tier
- **Annual License**: ₹25,00,000 / year (₹25L)
- Up to 25 autonomous agents and custom tool integrations
- Dedicated VPC deployment in customer's sovereign cloud region (e.g. AWS Mumbai / Azure Central India)
- High-availability active-passive cluster
- 24x7 Enterprise SLA (1-hour critical response time)
- Dedicated Forward Deployed Engineer (FDE) and Technical Account Manager (TAM)
- 1,000,000 monthly workflow executions included

### 3. Enterprise Scale Tier
- **Annual License**: ₹40,00,000 - ₹75,00,000 / year (₹40L - ₹75L)
- Unlimited agents, on-prem air-gapped deployment option
- Custom fine-tuned SLM/LLM inference nodes
- 15-minute emergency response SLA with dedicated site reliability engineers

## Commercial Terms & Payment Milestones
- Typical billing: 50% upon contract signing, 30% upon UAT / Sandbox sign-off, 20% on production go-live.
- Multi-year discount: 15% discount on 3-year commitments.
